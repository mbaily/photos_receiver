Send Batch to Server

Built with unqforge. The upload bearer token is already included. Batch-check version: hashes each original once, checks all hashes in one JSON request, and uploads only wanted originals. If everything already exists, the upload loop is skipped.

Signing is required before iOS can install this shortcut.

Download updated batch shortcut plist
Download unsigned shortcut (for Mac signing)

On iOS: download the plist, open unqforge, select Decompile and open the downloaded plist. Open the result in Build, then select “Sign & download .shortcut” and complete the human check. Open the signed download to add it to Shortcuts.

The web signing service receives the shortcut, including its embedded token. Alternatively sign locally on a Mac:

shortcuts sign -m anyone \
  -i 'Send Batch to Server.unsigned.shortcut' \
  -o 'Send Batch to Server.shortcut'

Then share photos or videos from Photos to “Send Batch to Server”. Replace the previous shortcut when installing this update. The final notification shows the upload count.
